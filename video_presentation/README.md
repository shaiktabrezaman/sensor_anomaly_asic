# 🎥 Project Video Presentation

This folder contains the video presentation for the **Persistence-Based Anomaly Detector for Structural Health Monitoring** project.

The video demonstrates the project architecture, Verilog RTL design, functional verification, logic synthesis, and ASIC physical implementation using SKY130A technology.

## ▶️ Watch the Presentation

**[Watch the Project Demonstration](https://drive.google.com/file/d/1GBcMMNceXeY6uRBMckHIR7ASwJvFfVjR/view?usp=sharing)**

## 📌 Topics Covered

- Project introduction and problem statement
- Proposed system architecture
- Verilog RTL design and finite-state machine
- Testbench and functional verification
- RTL simulation and waveform analysis
- Logic synthesis using Yosys
- Gate-level simulation
- OpenLane physical design and GDSII generation
- Static timing analysis and final results

## 🛠️ Tools and Technologies

- Verilog HDL
- Icarus Verilog
- GTKWave
- Yosys
- OpenLane
- SKY130A PDK
